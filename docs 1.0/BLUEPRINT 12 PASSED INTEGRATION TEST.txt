LANGKAH 4: PERBAIKI ENCOUNTER 403
================================================================
Tujuan: Memastikan middleware allowDoctorOrAdmin berfungsi dengan benar.

4A. Cek apakah allowDoctorOrAdmin sudah terdefinisi:
grep -n "allowDoctorOrAdmin" src/middleware/authMiddleware.ts

Jika tidak muncul, tambahkan dengan perintah:
cat >> src/middleware/authMiddleware.ts << 'EOF'

export const allowDoctorOrAdmin = (req: Request, res: Response, next: NextFunction) => {
  if (!req.user) {
    return res.status(401).json({ success: false, message: 'Unauthorized' });
  }
  if (req.user.role === 'DOCTOR' || req.user.role === 'ADMIN_BRANCH') {
    return next();
  }
  return res.status(403).json({ success: false, message: 'Forbidden: Doctor or Admin only' });
};
EOF

4B. Pastikan encounter.routes.ts mengimpor dan menggunakan middleware tersebut:
cat src/routes/encounter.routes.ts | grep -n "allowDoctorOrAdmin"

Jika belum, tulis ulang encounter.routes.ts:
cat > src/routes/encounter.routes.ts << 'EOF'
import { Router } from 'express';
import { authMiddleware, allowDoctorOrAdmin } from '../middleware/authMiddleware';
import {
  startEncounter,
  updateEncounter,
  completeEncounter,
  getEncounter,
} from '../handlers/encounter.handler';

const router = Router();
router.use(authMiddleware);
router.post('/', allowDoctorOrAdmin, startEncounter);
router.put('/:id', allowDoctorOrAdmin, updateEncounter);
router.post('/:id/complete', allowDoctorOrAdmin, completeEncounter);
router.get('/:id', getEncounter);
export default router;
EOF
